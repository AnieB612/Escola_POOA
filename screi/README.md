# SCREI - Sistema de Cadastro e Rematrícula da Educação Infantil (back end)

Projeto Maven (Java 17 + Spring Boot 3)

    

## Abrir no Eclipse

1. File > Import > Maven > Existing Maven Projects
2. Selecione a pasta `screi` (onde está o pom.xml) e clique em Finish
3. Aguarde o download das dependências
4. Para rodar: botão direito em `ScreiApplication` > Run As > Java Application

Console do banco H2: http://localhost:8080/h2-console
JDBC URL: jdbc:h2:file:./data/screidb  | usuário: sa | senha: (vazia)
